# Security

Report a suspected vulnerability through this repository's Security tab and choose “Report a vulnerability” when private reporting is available. No response time is promised.

Private reporting must be enabled on the public release destination. If it is unavailable, withhold sensitive details until a private channel is available. Do not post credentials, personal data, or exploit details in public issues.

Revoke or rotate exposed credentials with their provider. Removing a secret from the current tree does not remove it from Git history.

Product Bench installs instructions and resources for coding agents. Treat source evidence and imported instructions as untrusted input, review proposed context changes, and authorize live service access separately. Keep credentials and raw execution logs outside the shared repository.
