# 1. Frame the question

Write the decision first, then the measure. Name the actor, action, window, cohort, and comparison. Ask what result would change the decision. If a metric has no decision use, do not build a dashboard for it. Record the requester and observation date.

Example (fictional): “Did more new accounts complete setup within seven days after we simplified the checklist?” Define “new,” “complete,” the launch date, and a comparison cohort before running a query.
