# 7. Report for a decision

Lead with the answer and its confidence. Include the exact question, date range, query or API request, data freshness, numerator, denominator, exclusions, and caveats. Distinguish observation from explanation. Show one counterexample or competing interpretation when it matters. End with the decision, owner, and what would change the conclusion.

Do not paste raw customer records into a shared report. Keep saved queries in a reviewed location and rerun them before reusing an old number.
