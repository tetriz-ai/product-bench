# Adapting a document layout

Use the requested reader, format and reviewed design context to select a layout. Covers, icons, arrows, cards, callouts and chapter structures are optional tools; no particular palette, font, icon library or number of statistics is required.

Choose flow layout when length or image-driven pagination is uncertain. Choose fixed pages when explicit page geometry serves the task and fit can be measured. A small page count alone does not require a particular path.

When a page is crowded, preserve legibility: shorten low-value copy, simplify the figure, adjust appropriate spacing or add an explicit continuation. Recheck after changes. When a figure becomes unreadable at its final size, enlarge it or choose a clearer crop; do not claim high source resolution guarantees readable print.

Reuse reviewed inputs without another questionnaire or approval cycle. Missing nonessential brand inputs can use the clearly labeled neutral preview defaults. Ask only for a consequential unresolved choice, preserving the user's existing authorization.
